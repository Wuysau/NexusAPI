# Reproducible architecture CI

`.github/workflows/ci.yml` has one required verification job. Strict YAML parsing rejects duplicate keys. No required suite uses `passWithNoTests`, `continue-on-error`, or missing-fixture skips. Change planning reads the actual Git diff and Task `affects`/`validation` fields; every conditional gate runs conservatively, including when change scope is unknown. This trades extra runtime for complete coverage.

Node 24 installs the lockfile. Go 1.27 supplies formatting/vet and fixture certificate generation; pinned Linux Go and golangci images provide race detection and lint. PostgreSQL 17 and Redis 7 are disposable loopback services. Canonical migrations bootstrap separate test, E2E and Gateway fixture databases before testing. Migration tests intentionally reset their supplied test database; never set these URLs to a production database.

The job executes formatting, lint, typecheck, unit/contract/integration/security tests, real migration rollback tests, dependency audit, secret scan, Harness validation, Next/Worker/Budget builds, production Compose checks, four Docker builds, browser E2E and a required CycloneDX SBOM. The Go fixture starts actual Budget, PostgreSQL, Redis and local provider servers, closes Control Plane, then starts Worker and verifies exact settlement and replay. The Secret Plane fixture uses real TLS Vault/AppRole/Vault Agent and independent enrollment; mock crypto does not satisfy that gate.

`node scripts/ci-gate.mjs <gate>` records a fixed allowlisted command, exit code, actual test/pass/fail/skip counts, timing, revision and workflow run ID under `.test-artifacts/ci`. Required test gates reject zero tests or nonzero skips. Credential-bearing environment values and database URLs are redacted from captured command output. Never upload the surrounding `.test-artifacts/vault-reference` directory: it holds private fixture custody. The Secret Plane wrapper copies only explicitly constructed redacted receipts into the CI evidence directory.

Evidence uploads use `if: always()` and fail if no files exist. Image digests and the lockfile-generated `cyclonedx.json` accompany receipts. SBOM generation uses npm's built-in command, avoiding an unpinned transient download; see the [npm SBOM command](https://docs.npmjs.com/cli/commands/npm-sbom/). Package version `0.0.0` identifies this private, unreleased application; the actual build identity is the recorded commit and image digest.

Negative checks run the actual formatter and Docker parser on deliberately invalid inputs. Contract tests reject missing migration gates, duplicate job IDs, failure suppression and missing evidence uploads. Harness tests cover bad Task state/dependencies, while migration tests exercise real PostgreSQL failure/rollback. A broken production Dockerfile still fails the regular image build gate.

Local fixture inputs must be injected explicitly. `scripts/ci-fixtures.mjs` creates and resets only named convergence databases on loopback, including the explicitly selected `convergence_ci*` database. `CI_E2E_DATABASE_URL` selects a separate `convergence_e2e*` database; E2E starts and stops its own Next server on port 3320. `GATEWAY_BUDGET_INTEGRATION_DATABASE_URL` is restricted to loopback port55439/database `convergence_gateway27`; Redis uses port56381 and Budget3311. Required ports must be free. Local receipt execution does not claim a hosted GitHub run occurred.
