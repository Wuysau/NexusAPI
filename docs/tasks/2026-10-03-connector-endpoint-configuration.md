# Connector endpoint configuration

## Candidate and existing contract

The CLI validates remote origins and an explicit private-IP `/v1` upstream before reading pairing input or opening an identity file. Its fixed requests then append paths to the saved URL strings. Validation currently checks parsed query and fragment contents, which do not preserve every empty delimiter. The upstream path check also accepts decoded trailing slashes while construction trims only literal slashes in the original string.

An independent ignored real-HTTP characterization is checking the exact resulting paths before any production edit. Do not describe these local configuration mistakes as a cross-origin escape or authorization bypass.

## Design and interfaces

Keep `Config`, `New`, CLI actions and fixed endpoints unchanged. Reject literal query or fragment delimiters in all three configured URLs, including empty `?` and `#`, using the existing static configuration errors. Perform this check before any credential input, identity file or network action.

For accepted upstreams, retain the current decoded `/v1` path restriction and private-IP check. Canonicalize the approved path to `/v1` once after target validation; clear its encoded path hint so regular and encoded trailing slashes cannot alter subsequent fixed model/Chat paths. Preserve explicit scheme, host and port, including the current `localhost` to `127.0.0.1` mapping. Do not add host discovery, redirects, arbitrary endpoints or URL details to errors.

[Envoy's startup validation](https://www.envoyproxy.io/docs/envoy/latest/operations/cli#cmdoption-mode) provides the design principle: reject invalid configuration before serving or generating network traffic. The exact URL policy remains NexusAPI's existing fixed-endpoint contract. [Go 1.24 URL parsing](https://github.com/golang/go/blob/go1.24.0/src/net/url/url.go) distinguishes an empty query with `ForceQuery`, drops an empty fragment during parsing and stores decoded paths separately from encoded path hints; account for those representations explicitly.

## Verification and ownership

Capture real wrong-path observations and desired failures with synthetic fixtures before production changes. Formal tests must exercise actual CLI processes for `check`, `pair` and `run`, verify zero requests and unchanged identity files on rejection, and keep pairing input unread. Include accepted normal/trailing-slash and canonicalized encoded-slash model discovery/Chat controls through real HTTP, plus existing TLS/redirect/private-target checks. Never record credentials, query contents, prompts or private file paths in test diagnostics.

Root owns production, docs, validation and Git. The delegated agent owns only the two new `endpoint_config_network_test.go` files under `connectorclient` and `cmd/nexus-connector`, plus its ignored characterization artifacts. No database, migration, protocol, schema or external deployment changes are needed. Run relevant Go checks, connector integration, privacy checks and an independent scoped review before committing.

## Results

- The ignored actual-HTTP characterization records nine desired failures and ten passing controls on old production (connectorclient package 2.355 seconds, runner 4.162 seconds). Six empty query/fragment configurations each make one wrong request: remote POST `/` or local GET `/v1`, rejected by strict fixture routes. Three encoded trailing-slash upstream variants reach decoded `/v1//models` or `/v1///models`. Normal origins, a single remote trailing slash, plain upstream `/v1///` and an escaped unreserved path-name control work; nonempty query/fragment configurations and multiple remote root slashes remain rejected. This is a same-origin wrong-path observation with synthetic fixtures, without database or real credential redemption claims.
- Independent source review supports rejection before side effects and canonicalizing only the validated upstream path. Rejecting every encoded path would unnecessarily reject otherwise legal decoded `/v1` names. Stored remote origin strings continue to bind identities exactly.
- Formal tests capture forty-seven old leaves: fourteen desired library failures with eleven controls (4.749 seconds), and twenty desired CLI failures with two controls in the corrected stable fixture (4.455 seconds). The first CLI run had two ancillary healthy-readiness assertions in its negative fixture; that fixture was corrected before the stable baseline, and those ancillary errors are excluded from this evidence. Escaped unreserved names remain legal: their formal old failures concern the newly required canonical raw wire path, not previously broken decoded routing. Four invalid gateway/upstream pairing cases consume the synthetic mock one-time token and save an identity on old code; this is not a real Control Plane token redemption claim.
- The minimal production change rejects raw delimiters and canonicalizes only the approved private upstream. Root's fresh formal runs pass all twenty-five library leaves (2.397 seconds) and all twenty-two actual CLI leaves (6.456 seconds), including an open OS pipe with no token/EOF, exact fixed raw/decoded model and Chat paths, measured fixture request counts, private-CA HTTP/2, normal pairing/check/run and exact remote identity-origin preservation.
